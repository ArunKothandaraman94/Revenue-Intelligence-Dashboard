# Revenue-Intelligence-Dashboard
End-to-end BI project analyzing global retail revenue, profit, customer trends, and product performance using SQL, Python, and Power BI.

## SQL Analysis

### Data Preparation
- Imported Global Superstore dataset into PostgreSQL
- Renamed columns using snake_case
- Verified data quality and missing values

### Business Questions Answered
- Total Revenue
- Total Profit
- Profit Margin
- Sales by Category
- Sales by Market
- Sales by Region
- Top Customers
- Top Products
- Monthly Revenue
- Year-over-Year Growth
- Month-over-Month Growth
- Ranking Analysis using Window Functions

### SQL Concepts Used
- Aggregate Functions
- GROUP BY
- CASE WHEN
- CTEs
- Window Functions
- RANK()
- LAG()
- Date Functions
